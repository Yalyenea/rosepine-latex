# Empirical Spectra and the Marchenko--Pastur Law

Rose Pine A0 English poster (`article` + XeLaTeX).

`main.tex` is a **filled demo** (wall-poster type size, three packed columns), not a stub. Replace the banner and the `posterbox` blocks.

```bash
just build
```

## Portrait / landscape

Default is **A0 landscape**. For portrait, set `\posterlandscapefalse` before `\input{preamble}`.
